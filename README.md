# からだ記録

からだの異変を **日付 × 部位** で残していく記録アプリです。人体図から痛むところをタップし、症状とつらさを選ぶだけで、その日のログが1件たまります。

**→ https://kuru77.github.io/karada-log/**

依存ライブラリなし・ビルド不要。記録はブラウザの localStorage にだけ保存され、外部へは一切送信しません（通信するコードがありません）。オフラインでも開けます。

## なぜ人体図なのか

不調は「いつ・どこが」の2軸がそろって初めて意味を持ちます。テキストのメモ帳では、
「右肩が痛い」と書いた日が先月に何回あったかを数え直すことができません。

このアプリは部位を人体図の座標として持つので、記録がそのまま分布として見えます。
前面・背面あわせて46か所と、目・胃・気分・睡眠など図に描けない16項目をチップで選べます。

- 人体図の色は **つらさ（1〜5）** で、濃いほど強い症状です
- 「この日 / 直近30日 / すべて」を切り替えると、慢性的にどこが多いかが一目で分かります

## 記録するもの

| 項目 | 内容 |
|---|---|
| 日付 | 前後の日へ1タップで移動。過去の日にさかのぼって書けます |
| 部位 | 人体図（前面/背面）またはチップから選択 |
| 症状 | 痛み・しびれ・かゆみなど15種のタグを複数選択、自由入力も可 |
| つらさ | 1〜5の5段階（ごく軽い 〜 とても強い） |
| メモ | きっかけ・時間帯・対処などを自由記述 |

同じ日に何件でも記録でき、あとから編集・削除できます。

## 5つの画面

- **記録する** — 日付・人体図・入力フォーム・その日の記録一覧
- **履歴** — 部位／症状／期間／つらさで絞り込み、日付ごとにまとめて表示
- **カレンダー** — 月表示。記録のある日に色ドット、タップでその日へジャンプ
- **統計** — 総記録数・記録日数・平均つらさ、部位/症状ランキング、直近12週の推移
- **データ** — JSON/CSV書き出し、JSON読み込み、受診メモ用テキスト生成

## 受診メモ用テキスト

直近30日の記録を、日付順の箇条書きに整形してコピーできます。

```
【からだの記録】2026年8月22日（土） 〜 2026年8月27日（木）
（記録 3件／3日分）

■ 2026年8月22日（土）
  ・頭：つらさ 5/5（ズキズキ）

■ 2026年8月27日（木）
  ・右肩：つらさ 4/5（こわばり、痛み）
    午後から。温めると少し楽。
```

診察の場で「いつからですか」「どのくらいの頻度で」を思い出す必要がなくなります。

## データの持ち方

記録は `localStorage` の `karada-log-v1` キーに配列として入ります。

```json
{ "id": "...", "date": "2026-08-27", "part": "右肩", "syms": ["こわばり","痛み"], "sev": 4, "memo": "午後から。", "createdAt": 1787788242392 }
```

端末やブラウザを変えると引き継がれないため、データ画面から JSON を書き出しておくと安全です。
読み込み時は「いまの記録に追加」か「置き換え」を選べます。CSV は Excel 用に BOM 付きで出力します。

## iPhone で使う

iPhone 16 Pro Max（440 × 956pt）を基準に最適化しています。

1. Safari で https://kuru77.github.io/karada-log/ を開く
2. 共有ボタン → **ホーム画面に追加**

追加後はアドレスバーのないフルスクリーンで起動し、機内モードでも開けます（Service Worker がキャッシュします）。

- **セーフエリア対応** — Dynamic Island とホームインジケータを `env(safe-area-inset-*)` で避けます
- **フォーカス時の自動ズームなし** — 入力欄のフォントを16px以上に固定しています
- **タップ領域は最小40px** — 人体図以外のすべての操作要素で確保
- 保存ボタンは画面下に固定。ホームインジケータの上に余白を取っています

## 使い方（ローカル）

`index.html` をブラウザで開くだけです。サーバーもインストールも要りません。
（`file://` で開いた場合、Service Worker は登録されません）

## 注意

体調を記録するためのツールで、診断や治療の判断をするものではありません。
強い症状や急な変化があるときは医療機関にご相談ください。
